### B05. 이력서 PDF 갱신 절차
- 상태: 열림
- 등록: 2026-09-06 / 출처: `feat/content`
- 내용: 사이트의 이력서는 연락처(전화번호)를 뺀 공개용 PDF다. 원본과 공개용 두 벌을 유지한다. 서류 뷰어는 PDF를 직접 그리지 않고 `public/resume/page-N.webp`를 쓴다.
- 보류 사유: 이력서를 고칠 때마다 `public/resume.pdf`, 페이지 이미지 6장, `RESUME.pages`(`lib/desk/xp-apps.ts`)를 함께 바꿔야 하는데 이를 자동화할지 정하지 않았다.
- 후속 처리 경로: 갱신이 잦아지면 PDF에서 페이지 이미지를 뽑는 스크립트를 `scripts/`에 둔다. 당분간은 수동으로 하고 이 항목을 체크리스트로 쓴다.

### B04. 코드 패널 글꼴
- 상태: 열림
- 등록: 2026-09-06 / 출처: `feat/content`
- 내용: 프로젝트 창의 서비스 구조(코드 블록)는 `--ps-mono`(Consolas, Menlo, Pretendard 폴백)를 쓴다. 시스템에 고정폭 글꼴이 없는 환경에서는 ASCII 구조도가 어긋날 수 있다.
- 보류 사유: D2Coding 같은 한글 고정폭 글꼴을 서브셋으로 넣으면 번들이 커진다. 실제로 어긋나는 환경이 있는지 확인하지 않았다.
- 후속 처리 경로: 모바일과 macOS에서 구조도 정렬을 확인한 뒤, 어긋나면 ASCII 구조도에 쓰는 글자만 서브셋으로 넣는다.

### B03. XP 크롬의 음영 리터럴
- 상태: 열림
- 등록: 2026-09-06 / 출처: `feat/content`
- 내용: `globals.css`의 색 리터럴은 토큰으로 옮겼다. 다만 XP 크롬의 하이라이트와 그림자(`rgba(255,255,255,x)`, `rgba(0,0,0,x)`)는 그대로 두었다.
