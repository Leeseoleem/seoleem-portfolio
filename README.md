# seoleem portfolio

Windows XP 부팅 화면에서 3D 책상으로 이어지는 인터랙티브 포트폴리오 웹사이트.

## 스택

- Next.js 16 (App Router) / React 19 / TypeScript
- Tailwind CSS 4
- three + React Three Fiber + drei
- zustand

> 전체 스택과 버전은 `CLAUDE.md` 참고.

## 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

## 배포

- Vercel (예정). URL은 배포 후 기록
